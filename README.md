# GOOM

הקובץ הראשי הוא `index.html`.

ב־VS Code פותחים את תיקיית הפרויקט, לוחצים לחיצה ימנית על `index.html` ובוחרים **Open with Live Server**. אין צורך בהתקנות, npm או build. גם הקובץ הישן `GOOM 2026.dc.html` מפנה לאותו אתר.

- `index.html` — מבנה האתר והסקשנים.
- `site.css` — העיצוב הקיים.
- `cinematic.css` — ההירו, ההתאמה למובייל והמעברים.
- `mobile-first.css` — קומפוזיציית המובייל לפי הרפרנס, גלריית המגע והתאמת יתר האתר.
- `app.js` — נגן הפריימים, הגלילה והאינטראקציות.
- `assets/sequence` — 240 פריימים מהסרטון המקורי, בשתי רזולוציות, ונתוני הרצף.
- `assets/sequence/portrait` — הרצף האנכי החדש, 240 פריימים בגודל 720×1560.
- `scripts/build-portrait-sequence.py` — בניית הפריימים האנכיים ביחס גדלים אחיד.
- `mobile-preview.html` — תצוגת טלפון בתוך הדפדפן במחשב.
- `assets/ezgif-8bf509dc7bc9d281-jpg/enhanced` — גרסאות משופרות של 50 תמונות המקור. המקור נשמר.
- `.recovery` — גיבויי השחזור; אינם קובצי הכניסה לאתר.

האתר משתמש בקבצים מקומיים בלבד לצורך התצוגה. `support.js` וקובצי העורך הישנים נשמרו בארכיון הפרויקט, אך האתר אינו טוען אותם. עריכות מעתה מבצעים בקבצים הראשיים שמפורטים כאן.

פרטי בדיקות ותיעוד הגרסה הנוכחית: `qa/PORTRAIT-REBUILD-NOTES.md`.
